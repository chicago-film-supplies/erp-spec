> _"absorb into cogs"_

Answering the one question
`inbox/2026-08-17-oq-050-answered-wrapbook-itemises-wages-per-person-per-day-but-prices-burden-per-RUN-so-the-cost-rate-is-an-estimate.md`
left open: does Wrapbook's **1.49% platform fee** absorb into COGS with the wages, or sit in
administrative expense as a cost of outsourcing payroll?

## ⚠️ The question was already answered and should not have been asked separately

Owner, earlier the same day: _"our cost is just the payment to wrapbook."_ **The platform fee is
part of the payment to Wrapbook.** Splitting it out as a separate classification question read the
words of that sentence rather than its claim — the same pattern this session has hit repeatedly, and
the cheapest instance of it.

## Why the ruling is right on its own terms, beyond being consistent

- **The fee is not severable in the source document.** It is priced as a percentage of applicable
  wages, on the same invoice, in the same run. Sending it to G&A would require an allocation **the
  invoice itself does not make** — inventing a division the source document does not have, which is
  the opposite of how every other cost in this spec is treated.
- **It varies with the driver.** No crew engaged, no applicable wages, no fee. A cost that moves
  one-for-one with labor volume is a variable cost of labor, not a period overhead.
- **The fully-burdened-rate literature includes payroll service fees**, and the practical case is
  blunt: excluding it makes every W-2 job cost permanently 1.49% light.

## What changes

**The absorbed rate is the whole charge: 19.85% measured on run 759715**, not the 18.36% statutory
part. CFS's cost per W-2 hour is the Wrapbook invoice, undivided.

⚠️ **The cap analysis shifts, and in the useful direction.** The platform fee is **uncapped** — it
is charged on applicable wages with no annual base — so it joins Medicare and workers comp in the
floor:

|                             |       rate | capped?                  |
| --------------------------- | ---------: | ------------------------ |
| Employer FICA               |      6.20% | yes, at the SS wage base |
| Federal Unemployment        |      0.60% | yes, ~$7,000/yr          |
| Illinois State Unemployment |      7.05% | yes, ~$13,600/yr         |
| **capped subtotal**         | **13.85%** |                          |
| Employer Medicare           |      1.45% | no                       |
| Workers compensation — IL   |      3.06% | no                       |
| **Platform fee**            |  **1.49%** | **no**                   |
| **uncapped floor**          |  **6.00%** |                          |

⇒ A person's true burden falls from **19.85%** toward exactly **6.00%** as they cross the FUTA and
SUTA bases within a year. The floor is higher than the 4.51% recorded before this ruling, so the
systematic bias in a flat rate is slightly smaller — **and it is still systematic**, because 13.85
points of the 19.85 switch off mid-season.

## ⚠️ One consequence worth stating before it surprises somebody

**The fee follows the RAIL, not the classification.** The fee summary carries a `Contractor Wages`
line, so a 1099 paid _through Wrapbook_ incurs the platform fee while a 1099 paid _direct by
Zelle/ACH_ does not. Absorbing the fee therefore means **two people doing identical work can cost
differently because of an administrative choice about how they were paid.**

That is simply true under actual costing and it is not an argument against the ruling. It is an
argument for **one blended rate across the population** rather than per-rail precision — which the
apportionment already forces, since burden is priced per run and not per person.
